Conceitos Fundamentais Paradigmas de IA Teste seus Conhecimentos
Fundamentos

Agentes Inteligentes

Entidades que percebem o ambiente por meio de sensores e agem sobre ele através de atuadores visando maximizar uma medida de desempenho.

Resolução de Problemas

Algoritmos de Busca

Técnicas como Busca em Largura (BFS), Profundidade (DFS) e Busca A* (heurística) usadas para encontrar caminhos ótimos em espaços de estados.

Aprendizado

Machine Learning

Subcampo da IA onde modelos aprendem padrões a partir de dados históricos sem serem explicitamente programados para cada regra.

Deep Learning

Redes Neurais Artificiais

Estruturas inspiradas no cérebro humano (Perceptron, MLP) compostas por camadas de neurônios com pesos ajustados via Backpropagation.

Lógica

Representação do Conhecimento

Uso de Lógica Proposicional, Lógica de Primeira Ordem e Sistemas Especialistas baseados em regras (SE-ENTÃO) para inferência.

IA Moderna

Processamento de Linguagem Natural

Área focada na interação entre computadores e linguagem humana, base dos atuais Modelos de Linguagem (LLMs) e Transformers.
